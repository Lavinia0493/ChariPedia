# ChariPedia
Um site para visualizar todos os pokemons e favoritálos. Sistema de cadastro e login, favoritar pokemons, renomeá-los e remover da lista de favoritos. Projeto feito em python e framework flask.

##Como rodar no seu pc este site:
-No vs abra a pasta do projeto
-Crie um novo terminal(no vscode mesmo)
-Insira os seguintes comandos

python3 -m venv .venv  (linux)
py -3 -m venv .venv  (windows)

. .venv/bin/activate  (linux)
.venv\Scripts\activate  (windows)

pip install Flask

pip install requests

algumas configurações não obrigatórias(linux)
export FLASK_APP=app.py
export FLASK_DEBUG=1
export FLASK_ENV=development

flask run

segure ctrl e clique no link que foi gerado
